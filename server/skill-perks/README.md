# Skill Perks

Minecraft 26.1 的服务端 Fabric 扩展，直接读取 SimpleSkills 的采矿、挖掘和伐木等级。原版客户端通过服务端同步的 `minecraft:block_break_speed` 属性获得速度加成。

## 速度

持镐使用采矿等级，持铲使用挖掘等级，持斧使用伐木等级。默认每级增加 1% 挖掘速度：50 级增加 50%，99 级增加 99%。切换工具、升级后在 5 个服务器 tick 内更新，配置重载立即更新。

加成随当前手持工具生效，空手使用原版速度。每项技能的 `speedPerLevel` 可以分别调整。速度加成以独立的临时属性修饰符叠加到玩家身上，既有状态效果和附魔继续参与原版计算。

## 额外掉落

生存玩家用对应工具挖掉配置中的方块时，按当前技能等级抽取奖励。原有方块掉落照常生成，奖励额外掉在方块位置，每块最多额外掉落一份。每项奖励的计算公式为：

```
当前概率 = chanceAt99 × 当前等级 / 99
```

达到该奖励的 `minLevel` 后开放抽取。

采矿默认覆盖石头、圆石、深板岩、深板岩圆石、花岗岩、闪长岩、安山岩、凝灰岩、黑石和玄武岩：

| 额外物品 | 开放等级 | 99级概率 | 99级每挖一万块的平均数量 |
| --- | ---: | ---: | ---: |
| 煤炭 | 1 | 10% | 1000 |
| 粗铁 | 10 | 5% | 500 |
| 粗金 | 25 | 2% | 200 |
| 红石粉 | 35 | 1.5% | 150 |
| 青金石 | 45 | 1% | 100 |
| 钻石 | 60 | 0.15% | 15 |
| 绿宝石 | 75 | 0.05% | 5 |

例如 50 级时，煤炭概率约 5.051%，粗铁约 2.525%，粗金约 1.010%。99 级采矿的总额外掉落概率是 19.7%。

挖掘默认覆盖泥土、草方块、砂土、缠根泥土、灰化土、菌丝体、土径、沙子、红沙、砂砾、泥巴、黏土块、灵魂沙和灵魂土：

| 额外物品 | 开放等级 | 99级概率 |
| --- | ---: | ---: |
| 燧石 | 1 | 3% |
| 黏土球 | 1 | 2% |
| 铁粒 | 10 | 1% |
| 骨头 | 20 | 0.5% |
| 金粒 | 25 | 0.3% |
| 钻石 | 75 | 0.01% |
| 绿宝石 | 85 | 0.005% |

伐木默认提供速度加成。各技能的方块清单和奖励表均可配置。

## 安装与在线调参

把 `build/skill-perks-1.1.0.jar` 放入服务端 `mods/`，重启一次服务端。首次启动创建 `config/skill-perks.json`，SimpleSkills 中已有的等级继续使用。

编辑 `config/skill-perks.json` 后，管理员执行：

```
/skill-perks reload
```

速度、奖励物品、等级要求和概率立即生效。更换扩展代码或 jar 时重启服务端。

`chanceAt99` 使用小数，例如 `0.03` 表示 3%。每项技能奖励表的概率总和应在 0 到 1 之间。`count` 是单次奖励数量，`blocks` 是可触发额外掉落的方块列表。

## 构建与验证

使用相邻 `xiaoke-bridge/build.py` 的 Java 查找和编译缓存工具，需要 JDK 25、MC 26.1、Fabric API，以及缓存 `mods/simpleskills-1.4.4.jar`。默认缓存为项目上层的 `.cache/mc-26.1`，也可设置 `XKB_CACHE_DIR`。

```
python server/skill-perks/build.py
```

构建检查等级与速度、奖励开放等级、概率区间以及 99 级总掉率。真实服务端检查脚本为 `test/integration.mjs`，使用 `.cache/skill-perks-test` 下的独立服务器，记录协议同步的挖掘速度属性、采矿和挖掘额外掉落、伐木速度、换工具与在线重载结果。

实际验证结果保存在独立测试目录的 `integration-results.json` 和 `integration-server.log`。正式发布使用 `resources/skill-perks.json` 中的默认概率。

## 战斗和附魔（1.1.0）

所有数值按对应技能等级逐级增长，等级上限 99。

| 效果 | 每级增加 | 50级 | 99级 |
| --- | ---: | ---: | ---: |
| 近战伤害 | 0.5% | +25% | +49.5% |
| 远程伤害 | 0.5% | +25% | +49.5% |
| 护甲、保护附魔结算后的额外减伤 | 0.2% | 10% | 19.8% |
| 实际消耗箭矢的返还概率 | 0.25% | 12.5% | 24.75% |
| 每个普通经验等级的保留概率 | 0.3% | 15% | 29.7% |
| 附魔台词条提升概率 | 0.2% | 10% | 19.8% |

近战覆盖玩家直接攻击和重锤下砸，技能倍率应用于本次攻击伤害，随后由目标护甲结算。远程覆盖箭矢、投掷三叉戟，发射时记录等级倍率。

防御覆盖生物攻击、投射物、爆炸和魔法攻击，按护甲与保护附魔结算后的伤害乘以 `1 - 等级 × 0.002`。环境伤害沿用原版计算。

普通箭、光灵箭和药箭的实际消耗分别参与返还抽取，物品组件随原箭保留。附魔台与铁砧添加、合并附魔时，每个需扣除的经验等级分别参与保留抽取，操作的原等级要求继续生效。

附魔台结果存在可升级词条时，抽取一次升级机会，再随机选一个已有词条增加 1 级，最高达到原版附魔上限。青金石按原数量消耗。铁砧纯修理继续使用 SimpleSkills 的修理机制。

投射物命中时优先按远程归类经验，沿用 SimpleSkills 的远程经验倍率和最低伤害配置。原模组的近战经验机制继续处理直接攻击。

`combat` 和 `enchanting` 两段配置可通过 `/skill-perks reload` 在线重载。集成测试通过原版伤害、弹药消耗、附魔台和铁砧菜单验证；测试探针单独打包为 `skill-perks-probe.jar`，发布包为 `skill-perks-1.1.0.jar`。
