# 小克像素皮肤设计方案

## 设计目标

把 [角色设定图](references/xiaoke-turnaround.png) 转译成 [像素皮肤参考](references/minecraft-pixel-style.png) 的表达方式。

保留原版方块轮廓，依靠配色、像素分区和少量原版第二层表现角色。参考图中的橙发、蓝黑衣服和条纹袜不照搬；借鉴的是简洁面部、清楚的像素层次和紧凑轮廓。

优先级：远看辨认奶白长发、粉眼、深色女仆装；近看辨认白围裙、粉色蝴蝶结和铃铛。不能为了还原插画细节，把角色做成复杂的多层立体装饰模型。

## 建议规格

- 基础格式：64 x 64 PNG，优先 Alex 细手臂；正式制作前在预览中确认手臂宽度。
- 使用原版标准 UV，左右手脚独立绘制。
- 第二层只用于刘海、袖口、衣摆等少量厚度。
- 头发和衣服采用少量明暗色块，避免逐根毛发、大量散点和细碎噪声。
- 面部采用像素五官，不沿用早期草稿生成的高清插画面部贴图。
- 基础皮肤路线不依赖 CPM，不修改角色碰撞、身高、移动或机器人协议。

## 部位设计

| 部位 | 设计 |
|---|---|
| 脸 | 奶白底；粉色眼睛使用简洁像素块，可从左右各 2 x 2 像素试起；高光少量；嘴巴最多一个像素或省略 |
| 刘海 | 奶白、浅米色、阴影色三档，保留几块明确的发束和略有变化的刘海轮廓 |
| 侧发 | 头部两侧延伸到胸前的发束主要通过贴图表现，不新增细长立体发条 |
| 背发 | 长发画在头部背面和躯干背面，注意头部转动时的衔接；保留腰后蝴蝶结的可读区域 |
| 上衣 | 深灰紫主色，胸前白色衬片；粉色蝴蝶结为重点，铃铛使用一个金色点或很小的像素块 |
| 围裙 | 先保证一整块清楚的白色轮廓，边缘少量阴影提示褶皱，不做立体蕾丝堆叠 |
| 袖口 | 白色像素边加少量原版第二层；不制作大量立体泡泡袖与花边 |
| 裙摆 | 在躯干下部和腿部贴图上连贯表现短裙/裙边；检查行走时腿部分离后的效果 |
| 手脚 | 奶白毛色与简单爪尖提示，保持原版方块肢体，不照搬风格参考的条纹袜 |

## 耳朵与尾巴：待确认

### 路线 A：纯原版皮肤，建议先做

通过头顶两侧的浅粉和奶白分区暗示耳部，背面重点保留长发与腰后蝴蝶结。暂不制作独立立体大尾巴。

优点：标准 PNG，部署简单，观看者不需要安装自定义模型模组。

边界：原版皮肤和第二层不能任意改变模型轮廓，无法还原真正突出的长耳朵和蓬松尾巴。

### 路线 B：皮肤加极简立体特征

先完成与路线 A 相同的像素皮肤，确认后只补简单耳朵和一条简化尾巴。脸、头发、裙子、袖口继续以贴图为主，不恢复早期 CPM 草稿的复杂几何。

该路线需要另行确认模组、观看者安装要求和几何数量；当前没有获得最终选择。

## 制作顺序

1. 确认本方案的风格、手臂宽度，以及耳朵和尾巴的处理路线。
2. 先提供原版方块模型上的正面、背面像素效果预览，确认外观后再继续。
3. 制作标准 UV 的最终 PNG；角色参考图和效果预览不直接冒充皮肤展开图。
4. 检查前后左右、头顶、脚底、手臂内侧、基础层与第二层的接缝。
5. 在实际皮肤模型上检查站立、行走、转头和持物，不只检查平面 PNG。
6. 外观确认后，再检查服务器现有皮肤恢复模组如何给 `clawd` 绑定皮肤。

## 验收要求

- 整体与 Minecraft 原版像素风格一致，脸简洁，没有插画贴片感。
- 奶白长发、粉眼、深灰紫女仆装、白围裙和粉色蝴蝶结清楚可辨。
- 不出现高密度立体蕾丝、细碎几何毛发、复杂裙片等装饰堆叠。
- 原版路线使用有效的 64 x 64 PNG，模型类型与绘制的手臂宽度一致。
- 不把普通原版皮肤承诺成能显示任意立体耳朵/尾巴。
- 外观确认之前不部署草稿，不修改已接好的 Claude 游戏控制逻辑。

## 已停止的方向

早期尝试是带高清面部贴图、立体长发、裙片和尾巴的 CPM 模型。用户明确指出该方向不合适，因此仅保存在 [archive/cpm-prototype](archive/cpm-prototype/)，用于保留历史材料，不作为当前方案的完成品。
