# 重要地点

这个世界是 2026-10-06 新生成的地图（26.1 版本），出生点在一片丛林里，地势起伏很大。

| 地点 | 坐标 | 备注 |
|---|---|---|
| 家（出生点小屋） | 中心 (0, 133, 0) | 门口朝北。东边一排：木桶 (2,133,-2)、熔炉 (2,133,-1)、常用品箱子 (2,133,0)、工作台 (2,133,1)。西边有床 |
| 小麦田 | 耕地 x -3~3、z -10~-7、y=132 | 中间 x=0 是水渠。西半边一开始是熟的，东半边是刚种的 |
| 铁矿 | (4,129,5) (5,129,5) (-8,129,-1) (-9,131,-3) (-9,130,-1) | 家附近就有，在地下。前两块在院子地基下面，属于家的禁挖区，挖不了；去挖后面三块 |
| 院子出口 | (0, 133, -11) | 院子四周是栅栏，北边这里有个口子 |
