# 沙漠·带瞭望塔的长屋
> 适合什么时候看：想要一座塔；想站高一点看风景；家在开阔的地方
> 大点子：房子一头接一座细高的瞭望塔：3×3，里面一架梯子爬到顶，顶上插火把
> 标签：沙漠 平地 高处 塔 长屋 平顶
> 来源：原版沙漠村庄里的房子（结构文件 desert_fletcher_house_1.nbt），6×12×12 格，242 块。村民的家，小而完整，照着盖也不算抄，不过还是借点子、换成你自己的样子更好。

## 看图
- 东南.png、西北.png：从东南角和西北角看过去的样子，颜色是按方块名粗略上的。

## 大点子
1. **细高的塔**：一间长条平顶屋的一头，接一座 3×3 的塔，塔身九格高，转角用切制砂岩、墙面用平滑砂岩。屋子矮、塔高，一高一低很好看。
2. **梯子爬到顶**：塔里一架梯子直通塔顶，塔顶铺半砖，正中一截砂岩墙，墙上插一支火把，晚上远远就看得到。

## 小装饰
- 平顶屋的屋顶四角和墙中间立半砖，像一圈垛口。
- 门口盆栽仙人掌。

## 关键局部
塔的截面：
```
 切平切
 平梯平    ← 每层都一样，叠九层
 切平切
```

## 小克可以怎么用
- 想要塔不用盖很粗：3×3 外墙、中间一格放梯子，一层层往上叠就是塔。木头、石头都行。
- 塔顶插火把或者放灯笼，迷路的时候远远能看到家。
