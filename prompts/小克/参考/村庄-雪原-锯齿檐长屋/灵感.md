# 雪原·锯齿檐长屋
> 适合什么时候看：想盖长条形的房子；想让屋檐有花纹；想让一长面墙不单调
> 大点子：屋檐用半砖和木板交替排成一排锯齿；窗户一格玻璃一格木头隔开，排一长溜
> 标签：雪地 长屋 窗户 装饰
> 来源：原版雪原村庄里的房子（结构文件 snowy_medium_house_2.nbt），14×9×7 格，409 块。村民的家，小而完整，照着盖也不算抄，不过还是借点子、换成你自己的样子更好。

## 看图
- 东南.png、西北.png：从东南角和西北角看过去的样子，颜色是按方块名粗略上的。
- 材料.md：用了哪些方块、各多少。

## 大点子
1. **锯齿屋檐**：长长的人字顶，最外面一圈屋檐不是一整排，而是“半砖、木板、半砖、木板”交替，看着像一排小锯齿，雪落在上面一凹一凸。
2. **窗户排一长溜**：长墙上一格玻璃板、一格去皮云杉木交替，像一排小格子窗。

## 小装饰
- 墙全用去皮云杉木（比原木整齐，颜色浅）。
- 门在长边正中，两边对称。
- 屋顶积着雪（雪层）；屋里两张床、熔炉。

## 关键局部
屋檐从侧面看：
```
 半木半木半木半木半    ← 一凹一凸
  木木木木木木木木
```
长墙：
```
 木玻木玻木玻木玻木
```

## 小克可以怎么用
- 长房子最怕一面墙平平的：屋檐交替放半砖和木板，窗户隔一格开一扇，就有节奏了。
- 这条小房子也能用：只在屋檐那一圈换着放就行。
