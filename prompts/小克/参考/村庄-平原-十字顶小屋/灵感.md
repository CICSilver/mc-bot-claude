# 平原·十字顶小屋
> 适合什么时候看：想让一间小方屋看着不单调；想做十字屋顶；门口想有两小块菜地
> 大点子：十字屋顶：两道人字顶交叉，四面都是山墙
> 标签：平地 小屋 十字顶 菜园
> 来源：原版平原村庄里的房子（结构文件 plains_small_house_8.nbt），8×9×9 格，250 块。村民的家，小而完整，照着盖也不算抄，不过还是借点子、换成你自己的样子更好。

## 看图
- 东南.png、西北.png：从东南角和西北角看过去的样子，颜色是按方块名粗略上的。
- 材料.md：用了哪些方块、各多少。

## 大点子
1. **十字屋顶**：屋子只有 5×5，屋顶却是两道人字顶交叉成十字，东西南北四面都有一个三角形的山墙。小房子一下子就不是方盒子了。屋面是橡木楼梯，正中最高处是一块橡木半砖。
2. **门口的两小块菜地**：门前门后各一小块耕地，中间一格水，种着小麦，用草方块围边。房子和地连在一起，像住着人。

## 小装饰
- 四个墙角立原木柱子，墙是圆石，柱子和墙一深一浅。
- 每面墙中间一扇玻璃板小窗；门边、屋里墙上插火把。
- 门前一级圆石楼梯当台阶。

## 关键局部
屋顶从南往北看（中间那一列最高）：
```
   _S_          S = 半砖（屋脊）
  /   \         / \ = 楼梯
 /     \
|山  墙 |
```
四面一样，四个斜面在角上交成斜沟。

## 小克可以怎么用
- 盖小房子时最省事的“变好看”：墙不变，只把屋顶从一道人字顶换成十字顶。图纸里屋顶那几层，东西向和南北向各画一道人字顶，交叉的格子楼梯会自己拐成内角。
- 门口种两小块地，正好和手册《种田和动物》对上。
