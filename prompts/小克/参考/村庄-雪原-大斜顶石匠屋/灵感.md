# 雪原·大斜顶石匠屋
> 适合什么时候看：想要屋顶大、墙矮的房子；想要一根真的烟囱；喜欢木头配白石头
> 大点子：屋顶一直压到墙根（大斜坡，几乎从地面起），一根石头烟囱从屋顶穿出来
> 标签：雪地 尖顶 烟囱 小屋
> 来源：原版雪原村庄里的房子（结构文件 snowy_masons_house_2.nbt），9×10×9 格，373 块。村民的家，小而完整，照着盖也不算抄，不过还是借点子、换成你自己的样子更好。

## 看图
- 东南.png、西北.png：从东南角和西北角看过去的样子，颜色是按方块名粗略上的。
- 材料.md：用了哪些方块、各多少。

## 大点子
1. **大屋顶压到墙根**：屋顶从离地两格的地方就开始往上斜，两边各伸出去两格当檐，墙几乎被屋顶盖住，房子像躲在一个大屋顶下面，雪天很暖和的样子。
2. **石头烟囱**：屋子一侧砌一根闪长岩烟囱，从屋里一直穿出屋顶，顶上放一截闪长岩墙，挂一盏灯笼。

## 小装饰
- 墙框是去皮云杉木，屋顶是云杉木板，最外沿一圈半砖。
- 屋里切石机、熔炉。
- 门边、屋檐下挂灯笼。

## 关键局部
从山墙那头看：
```
       半
      木木木
     木木木木木
    木木 烟 木木
   木木 木  木木
  木木 木 门 木木     ← 屋顶两边低到离地两格
```

## 小克可以怎么用
- 想要“雪山小屋”的感觉：墙只盖两格高，屋顶从墙顶外面一格开始斜，斜到很高。
- 烟囱用石头砌，顶上点一个营火就会冒烟（见《中世纪新手小屋》）。
