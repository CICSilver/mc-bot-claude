# 沙漠·两层平顶屋
> 适合什么时候看：想盖平顶房子；想要屋顶露台；住在沙漠或者喜欢砂岩
> 大点子：两块平顶房错开叠成两层，屋顶当露台（梯子上去）；墙顶一圈按钮当梁头
> 标签：沙漠 平地 两层 平顶 露台
> 来源：原版沙漠村庄里的房子（结构文件 desert_medium_house_2.nbt），11×9×7 格，326 块。村民的家，小而完整，照着盖也不算抄，不过还是借点子、换成你自己的样子更好。

## 大点子
1. **盒子错开叠**：一楼是一个长方形，二楼是一个小一点的方块，叠在一楼的一头，不是正中间。没盖二楼的那半截一楼屋顶，就是露台。
2. **屋顶露台**：屋里一架梯子爬上二楼和屋顶，屋顶边上一圈平滑砂岩半砖当矮栏。

## 小装饰
- 每层墙顶外面一圈丛林木按钮，像伸出墙外的木梁头（沙漠房子常见）。
- 门口、窗台放盆栽仙人掌。
- 门是丛林木门，门前一级台阶。

## 关键局部
侧面：
```
    半半半半半
    砂砂 砂砂      二楼（小块）
 半半砂砂砂砂砂     ← 露台在左边这半截屋顶
 砂砂砂砂砂砂砂
 砂砂门砂砂砂砂
```

## 小克可以怎么用
- 平顶房子很好加二楼：在屋顶的一角再盖一个小方块，剩下的屋顶围一圈半砖，就是晒太阳的露台。
- 按钮当梁头：墙顶外侧隔一格贴一个木按钮，任何墙都能用。
