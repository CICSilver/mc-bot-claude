# 骨架·水上吊脚屋
> 适合什么时候看：家在湖边、河边、海边，想把房子盖到水面上；想有个能直接钓鱼、停船的家
> 大点子：原木柱子插进水里撑起一片木平台，平台上一间小屋，四周一圈栏杆，角上伸出一段拴船的小码头
> 标签：水边 水上 码头 钓鱼
> 来源：小克的 Claude 照着“村庄里没有、但小克可能会想住的房子”画的骨架，15×10×12 格的示意（连岸和水一起）。只是一个骨架：形状和做法照它来，大小、材料、装饰全按你家那块地和你的喜好改。

## 骨架怎么搭
1. **柱子**：从岸边往水里，每隔 3 格立一根原木柱子，从水底一直到比岸高一格。站在岸上或者已经铺好的板子上一格一格往外放，别潜下去。
2. **平台**：柱子顶上铺一层木板，比岸高一格；平台靠岸那一边用两块半砖接到岸上，走上去不用跳。
3. **栏杆**：平台四周一圈栅栏，靠岸那边留个口。
4. **小屋**：平台中间盖一间 5×4 的小屋，四角原木，人字顶两头用木板补成三角形山墙。门朝岸那边。
5. **拴船的小码头**：平台一角再往外伸 3 格半砖，尽头放一盏灯笼，船停在旁边。

## 关键局部
侧面（右边是水）：
```
      楼楼楼
     楼 屋 楼
     栏屋屋屋栏
 岸岸半木木木木木木半半灯   ← 平台比岸高一格
 岸岸 原   原   原        ← 柱子
 岸岸水原水水原水水原水水
```

## 顺着地形
- 水浅（一两格）最好盖：柱子短。水深的话柱子也一样往下接到底。
- 平台不用方方正正，顺着岸线弯一点更自然；可以跟《橡木小码头》《草原·水上高脚屋》一起看。

## 小克可以怎么用
- 你爱吃鱼：门一开就能钓，钓上来放进屋里的木桶。
- 平台大一点就能放长椅、花盆，傍晚坐着看水。
