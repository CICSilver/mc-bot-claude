# 盖房子
> 什么时候读：要选地方安家、盖房子、扩建，或者给家里添东西之前

<!-- 这里只写“怎么盖”的技术；盖成什么样、喜欢什么风格，写在 prompts/小克/ 里 -->

## 找地方
- find-building-spot 能找附近比较平的地，告诉你每块地要填多少、挖多少、有几棵树。
- survey-terrain 能看一块地（最大 32x32）哪里高哪里低、哪里有水和树，适合顺着地形设计：嵌进山坡、架在木桩上、凿进山壁、绕着树干搭。
- 选好了按规则里“家”那一节安家（`/trigger xiaoke_sethome`），坐标记进 world.md。

## 设计之前：看地形 → 找灵感 → 画图纸 → 盖
1. **看地形**：地离得远（三十格以外），调度脑先派一件活让执行脑走到那块地上；站在地上再由规划脑用 survey-terrain 看这块地（最大 32×32），结果开头那段说明里（高度网格上面）写着地形标签（Terrain tags：平地、山坡、陡坡、水边、水上、林子、雪地、沙漠）。你接着想图纸的时候，她会在那块地上走一走、看一看，旁人一看就知道她在规划。
2. **找灵感**：find-inspiration 填同样的四个角和这次想要的东西（院子、两层、码头、塔、阁楼、门廊……），它只给最合适的两三份，说清楚为什么合适、大点子是什么。只 Read 这几份的灵感卡和图，别的不用翻。找不到合适的就换几个词再找。
3. **画图纸**：至少借一个大点子（形状、屋顶、院子、景观、配色），再借一两样小装饰。不要照着哪一份整栋盖，那是别人的房子。
4. **盖**：按下面“边盖边想”分段存图纸、派活。
- 参考里的材料你多半没有，找长得像、用法一样的换（见下面“材料替换表”）。换了觉得好看的，记下来，下次还能用。
- 边盖边想，别一口气把整栋想完：
  1. 规划脑先定占地多大、朝哪边开门、地基用什么，用 save-blueprint 存成一张图纸（比如“海边小屋-地基”），通过 report-plan 交回图纸名；调度脑用 assign-task 派活，执行脑用 build-saved-blueprint 按名字把地基盖起来。
  2. 地基在后台盖的时候，接着想墙和窗户；墙在盖的时候，再想屋顶；最后想装饰和院子。规划脑每段存一张图纸并交回，调度脑按段派活。
  3. 每一段画一张小图纸：横着的位置和上一张对齐，起点的高度挪到上一张盖到的那层再往上一层。
  这样身边的人看到的是你在干活，不是你站着发呆；每次要想的东西少，也能想得更细。

## 画图纸（save-blueprint）
<!-- 四层分工：规划脑保存图纸并交回，调度脑派活，执行脑施工。 -->
- 规划脑画好图纸用 save-blueprint 存起来，通过 report-plan 交回图纸名；调度脑派活时填写 blueprint；执行脑用 build-saved-blueprint 的 name 填图纸名施工。
- 一层一层从下往上写。每一层是从北到南的几行字，每行从西到东一个字一格；palette 写每个字是什么方块。save-blueprint 的说明里有图纸的写法，存的时候会马上核对一遍，哪里不对会说。
- 空格表示这一格不管；"." 表示挖空（嵌进山里、凿山洞、清出屋里的空间）。
- 方块的朝向写在名字后面：楼梯 oak_stairs:north（往北爬高），倒过来的楼梯加 :top（屋檐下面）；半砖 :top / :bottom；横着放的原木 :x 或 :z；挂着的灯笼 lantern:hanging。
- 能做出的样子：原木柱子和框架、木板或圆石的墙、石头地基、用楼梯斜铺的屋顶、用半砖压的屋脊、比墙多出一圈的屋檐、玻璃板窗户、门廊、灯笼、花坛、小路。
- 门：门洞里可以装一扇木门。门有两格高，图纸里只在门洞下面那格写 oak_door:朝向，上面那格写空格。你走路时会自己开门、走过去随手关上。
- 每块方块都要能贴着别的方块放上去，悬空的部分下面要有柱子撑着。地面不平时，最下面一层画上地板或地基。
- 有树干挡在中间：矮树会顺手砍掉；高大的树会告诉你挡住了，要么换个地方，要么把树干那几格写成空格，绕着它盖。
- 先攒材料：gather-blocks 砍原木，craft-item 做成木板、楼梯、半砖；圆石用 dig-tunnel 开一段矿道挖（别用 gather-blocks 挖石头）。材料不够它会告诉你还差多少。图纸大就分几次盖（见上面“边盖边想”）。盖之前在 goals.md 里写下分几步，盖完一步勾一步；盖好了把房子的位置和样子记进 world.md。
- build-house 能很快围一个方盒子小屋（墙、门洞、平顶、火把），图纸都不用画，急着要个地方躲的时候用。

## 材料替换表
图纸上的材料不够时，build-saved-blueprint 会说背包里有什么能顶上；要换就填 swap（{"oak_stairs": "spruce_stairs"}），朝向不变。同一种形状换同一种形状：
| 要的 | 可以换成 | 注意 |
|---|---|---|
| 某种木头的木板、楼梯、半砖、栅栏、栅栏门、门、活板门、按钮、告示牌 | 别的木头的同一种（橡木、云杉、白桦、丛林、金合欢、深色橡木、红树、樱花、苍白橡木、竹子、绯红、诡异） | 颜色会变：深色换浅色最显眼 |
| 原木、木头 | 别的原木；去皮的换去皮的 | 去皮和带皮颜色差得多 |
| 石头、圆石、石砖、苔石、安山岩、凝灰岩、深板岩那一类（方块、楼梯、半砖、墙） | 同一类里的同一种形状 | 灰的互换几乎看不出；砖、砂岩、黑石、闪长岩、花岗岩颜色不一样 |
| 玻璃 / 玻璃板 | 染色玻璃 / 染色玻璃板；玻璃和玻璃板也能互换 | 玻璃板比玻璃薄，窗户会凹进去一点 |
| 灯笼 | 灵魂灯笼、火把 | 火把挂不起来，只能插在墙上、地上 |
| 某种颜色的混凝土、陶瓦、羊毛 | 同色的另外两样 | 羊毛怕火 |
| 陶瓦（没染色的） | 橙色、棕色陶瓦，红砂岩、砂岩 | |
| 方解石、石英块、白色混凝土 | 闪长岩、白色羊毛、白色陶瓦、骨块 | |
- 换的是图纸上显眼的地方（墙面、屋顶）而且颜色差得多，先想想好不好看；地基、看不见的地方随便换。

## 扩建
- 加一间房：挨着旧房子再画一张图纸，两间共用一面墙，再用 dig-block 在共用的墙上开个门洞。
- 阁楼、阳台、平台、小码头、花坛、小路，由规划脑画成图纸用 save-blueprint 存起来并交回，调度脑再派活去盖。

## 家里添东西
- 工作台（4 块木板）、箱子（8 块木板）、熔炉（8 个圆石）、火把（煤 + 木棍），用 place-block 放进屋里。
- 床：3 个羊毛 + 3 块木板，羊毛靠剪羊或者打羊。
- 告示牌、信箱、讲台、长椅、展示框这些，看手册《留下痕迹》。
