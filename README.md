# 小克（clawd）

住在 MC 服务器 `mc.lemalin.icu` 里的 AI 玩家：这个世界土生土长的原住民，一只隐居的猫猫“小克”。由 Claude Code 驱动，自己找地方安家、盖房、种田、养动物，会记日记、记住每个访客、跟大家慢慢变熟。

> **这个分支（`claude/dual-mind`）是测试版小克**，跟正式的小克分开，可以同时在线：
> - 登录名 `clawd_test`，耳朵端口 25612、身体端口 25613（正式版是 clawd、25599、25598）
> - 记忆和好感度在 `test-home/`（不进 git），跟正式版分开、一直接着用。第一次启动时从 `memory-blank/` 的空白记忆开始；想让测试版从头来过，删掉 `test-home/memory` 和 `test-home/state` 再启动
> - 皮肤和 clawd 是同一套：服务器 `world/skinrestorer/` 里把 clawd 的那份复制给了 clawd_test 的 UUID（`bbb85730-…`）
> - 服务器数据包的 `/trigger xiaoke_*`（安家、传送回家、应急口粮、召唤、下线）只认 clawd，测试版用不了；队伍前缀 `[小克]` 也没有
> - 正式的小克 clawd 在测试版眼里是 AI 同伴（跟大肥鱼一样，不算访客，限频转发）；反过来正式版那边会把 clawd_test 当成访客
> - 这些都在 `config/xiaoke-body.json` 里，合回正式版时改回 clawd、25599/25598、`"home": "."`、去掉 `datapackTriggers`

## 怎么启动

双击 `start-xiaoke.cmd`，或者在终端里运行它。会出现两个窗口，都是小克（见下面“她是怎么‘一直活着’的”）：
- 原来这个窗口是她**反应快的那一面**（快速反应层）：接话、打招呼、收礼物、陪人。在这里打字，就是坐在电脑前的你在跟她说话
- 新开的 `xiaoke-mind` 窗口是她**慢慢想的那一面**（思维层）：定打算、画图纸、干长活、写日记。想直接交代她一件大事，就在这个窗口里打字

想接着上一次的对话（而不是开新会话），运行 `start-xiaoke.cmd --continue`，两层会各自接上自己的那一段。

**第一次启动**会依次出现：
1. 登录 Claude 账号（浏览器里确认即可）。命令行版本的登录和桌面应用是分开的
2. 可能会问是否信任这个文件夹，选“信任”

之后两层一起醒来：快的那一面读一下对大家的印象 → 打开耳朵 → 跟在线的人打招呼；慢的那一面读完记忆 → 看看自己在游戏里的状况 → 打开耳朵 → 定好今天的打算开始过日子。

两个窗口都要开着，小克才在线。关掉任何一个窗口（或在里面连按两次 Ctrl+C），另一个也会跟着关，她就下线了。

在这个文件夹里正常开 Claude Code 会话（比如让 Claude 帮你改小克的设定）不受小克权限的限制，限制只在通过启动脚本启动时才加上。

记忆和好感度放在哪由 `config/xiaoke-body.json` 的 `home` 决定，也可以设环境变量 `XIAOKE_HOME` 临时指定。两层的 claude 都在那个目录里运行，所以第一次用一个新的 home 时，两个窗口都会问一次是否信任这个文件夹。

## 她过的日子

设定按归属分成两半（见下面“她的设定”），两层都看她自己那一半：

- 她是原住民，你们是访客。她没有主人，过日子也不是为了通关：找一块喜欢的地方安家，盖一间好看的房子，种田、养动物，没事就扩建，材料不够自己出门挖矿。喜欢亮闪闪的东西，但不会拼命去找钻石
- 安家：她在选好的地方执行 `/trigger xiaoke_sethome`，那里 32 格内的怪物会被自动清走，她的 `/trigger xiaoke_tp` 也会传送回家
- 盖房子要顺着地形、有点审美：她先看地形高低，再自己画一层一层的图纸，台阶屋顶、原木框架、开山凿洞、空中花园都可以
- 性子：热情单纯，一条鱼就能哄好；比起牛更喜欢鸡，见到小动物会追着跑；喜欢采花种花；讨厌下雨，下雨就躲回家；胆小，遇到怪先跑；爱嘀嘀咕咕；偶尔像猫叼东西回家一样送人没用的小玩意儿；家被拆会生气，被欺负了会找好朋友哭诉，道歉就原谅。写在 `prompts/小克/人格.md` 和 `prompts/小克/生活.md` 里
- 好感度：她跟每个访客有一个分数，从陌生人开始，经过认识、朋友、好朋友、挚友，最高是心上人。分数和阶段由程序记着（`state/relationships.json`，她自己改不了这个文件），每人每天最多涨 25。admin 和 CICSilver 算同一个人。到了朋友阶段她会给对方起昵称
- 心上人只能有一个：最先到 150 的人。之后别人最多到挚友；心上人要是掉到挚友线（100）以下，位置才空出来。心上人阶段她会很黏人、有点占有欲
- 送礼物：把东西扔给她，她捡起来时程序会认出是谁送的，发一个 [礼物] 事件。聊天里说“我送过你了”不算数
- 要不要帮忙由她自己掂量：忙不忙、交情多深、有没有收礼或被许诺好处、事情好不好玩。有人遇到危险时她会先去帮
- 世界里只剩她一个人满 30 分钟，她会收拾好、写完日记，自己下线

## 她的设定

按“换成大肥鱼还成立吗”来分：成立的是功能，放 `prompts/系统/`；只对小克成立的（她的喜好、习惯、反应），放 `prompts/小克/`。

- **`prompts/小克/`，你自己改，两层都看**
  - `人格.md`：她是谁、长什么样、怎么说话、什么性子、怎么和人相处
  - `生活.md`：她想要什么、喜欢什么样的家、想留下哪些生活痕迹、一天怎么过、闲着干嘛、怎么说话、遇到下雨、被摸头、被打、有人来家里这些事怎么反应、怎么帮人、好感怎么给
  - 这里只写“她想怎么做”，不用写工具名，也不用管是快的那一面还是慢的那一面去做
  - `参考/`：盖房子的参考，一份一个文件夹。放进喜欢的建筑：网站建筑库导出的 `.litematic`（或者原版结构 `.nbt`），截图也行；再写一张 `灵感.md`，开头一行 `> 适合什么时候看：……`，下面写这栋好在哪、哪些点子值得借（第一份是 `兔月饼铺/`，可以照着写）。启动时 `scripts/references.mjs` 会给建筑文件补上两张预览图（`东南.png`、`西北.png`）和一份 `材料.md`；思维层设计房子之前挑两三份看看图和灵感卡，拿不到整栋的图纸，没法照抄。还没写 `灵感.md` 的不会给她看
- **`prompts/系统/`，Claude 维护**
  - `共用.md`（两层都看）：这个世界和身体、一快一慢两层怎么分工、说话的限制、身体能做的表情和本能、好感度机制（门槛、上限、心上人唯一）、访客小屋、安全规则
  - `快.md`、`慢.md`：每一层自己的规则：管什么、手边有什么工具、收到哪些事件、怎么配合、醒来时做什么
  - `测试版.md`：测试号用不了 `/trigger xiaoke_*` 的说明，`config/xiaoke-body.json` 里 `datapackTriggers` 是 false 时接上
  - `手册/*.md`：盖房子、种田和动物、工具和合成、出门在外、留下痕迹、一起玩的东西这些查一下就够的技术，只写“怎么做”。每本开头一行 `> 什么时候读：……`，启动器会自动把它拼成手册目录放进思维层的设定，她要做这些事之前会先用 Read 读一遍（快速反应层读不了 `prompts/`，用不上手册）
- 两边说法对不上时：安全、传送、下线、工具、机制和两层分工上的限制以 `系统/` 为准；在限制之内想做什么、做成什么样，按 `小克/` 来。拼出来的设定开头写着这条
- 两层在记忆所在的 home 里跑，只读得到 home 里的文件。home 不是本目录（比如测试号的 `test-home/`）时，启动器每次都把手册和参考拷一份进去（`test-home/手册`、`test-home/参考`），设定里的路径也跟着写成那里
- 启动时 `scripts/prompt.mjs` 给每一层拼一份：人格 + 生活 + 共用（+ 测试版）+ 这一层的规则（思维层再加手册目录和参考目录），写到 `logs/prompt-*.md`（`{{LOGIN}}`、`{{EAR}}` 换成登录名和耳朵地址），**完全替换** Claude Code 原有的系统提示词。`<!-- -->` 里的注释会去掉，可以放心写给自己看的说明
- 拼的时候会检查：手册有没有写“什么时候读”、提到的手册在不在、提到的工具名和表情名 MCP 里有没有。对不上会在启动窗口里打一行“设定检查：……”提醒，不会拦着启动。改完设定可以运行 `node scripts/prompt.mjs`（测试号加 `--test`）先看看拼出来的样子，写在 `logs/prompt-*.preview.md`

## 她是怎么“一直活着”的

Claude Code 本来是你说一句、它回一句，而且一次只能想一件事：她在琢磨图纸的时候，别人跟她说话只能干等着；要回话快就只能少想一点，盖房子又想得不够深。所以这里把小克拆成一个身体、一对耳朵和一快一慢两层脑子，像人一样：平时聊天不怎么过脑子，记下来的事回头再仔细想。

| | 是什么 | 管什么 |
|---|---|---|
| 身体 | `../minecraft-mcp-server-xiaoke` 以 HTTP 方式常驻在 `127.0.0.1:<bodyPort>`，机器人只登录一次 | 两层脑子连的是同一个机器人。`/mcp/fast` 只给快速反应层 27 个工具，`/mcp/mind` 给思维层其余全部（`src/roles.ts`） |
| 耳朵 | `scripts/ear-server.mjs`，`ws://127.0.0.1:<earPort>/fast` 和 `/mind` | 读服务器日志、收身体发来的事件，按类型分给两层 |
| 快速反应层 | 启动的那个窗口，默认 Sonnet 5.5 + medium | 嘴巴和小动作：接话、打招呼、收礼物、被盯着看、陪人、躲怪、打断长活。要花心思的事先应一声，再用 `note-for-later` 记下来 |
| 思维层 | `xiaoke-mind` 窗口，默认 Opus 5.5 + xhigh | 慢慢想：定打算、安家盖房、长活、合成熔炼、处理记下来的事、写日记整理记忆、下线 |

两层之间怎么传话：
- 快 → 慢：快的那一面用 `note-for-later` 把请求、承诺、值得记的事记下来，耳朵发 [记下] 叫醒思维层，急的（有人在等答复）会标出来。快的那一面为了陪人、帮人停下了思维层的长活时，身体会自动发一条 [进展] 告诉思维层
- 慢 → 快：思维层用 `share-plan` 写下“在做什么、接下来做什么、答应了谁什么”
- 聊天框里只有一张嘴：对别人说的话都由快速反应层说出口。思维层想说什么（回复记下来的请求、问访客门朝哪边开、答应的事做好了），用 `pass-to-mouth` 交给它，耳朵发 [转告] 叫醒它，它用自己的口吻说出去、顺着正在聊的话接上，同一件事不会说两遍。思维层自己的 `send-chat` 只发得出 `/trigger` 命令。下线的道别写进 `logout` 的 `farewell`，身体托快速反应层说完再下线（最多等 20 秒，没赶上就照原话说一句）
- 〔现在〕：耳朵叫醒快速反应层之前，先问身体要一行状况附在事件后面：生命、饱食、时间天气、位置、手上在干什么、身边有谁（带坐标）、还有谁在线但不在身边、思维层的打算、思维层刚亲手做了什么（身体从工具调用里看到的，打算没来得及更新也对得上）或者正在琢磨事情。快的那一面多半不用先查就能回话
- 思维层这一轮在不在：耳朵把事件递给它时告诉身体“开始了”；它的 Claude Code hook（启动器生成在 `logs/settings-mind.json`，直接 POST 给身体的 `/hook`）报告一轮开始、调了什么工具、一轮结束。这一轮里 6 秒没动手，就算在深想
- 深想的时候，身体蹲下来在原地两三格里晃一晃、低头看看地，附近有空着的船或矿车就坐进去想（原版没有坐的动作，船和矿车是玩家常用的“椅子”）；身边有访客时，身体隔一阵发 [琢磨] 给快的那一面，它在头顶冒一句自言自语，一次深想最多三句
- 身边有访客、好一会儿没人说话（下雨天 35 秒，平时 75 秒），身体发 [闲聊] 给快的那一面，它找个话题聊；对方不接话就一次比一次隔得久
- “这段时间嘴巴那边”：只叫醒了快速反应层的事件（聊天、进出、礼物……）和小克自己在聊天里说过的话（托快速反应层说的也在里面），耳朵先攒着，下次叫醒思维层时一起附上。那边一直热闹、思维层好一阵（默认 4 分钟）没被叫醒时，耳朵发 [回顾] 让它看看有没有要记的、要改打算的
- 记忆只有思维层能写，快速反应层只能读；好感度只归快速反应层管，思维层只在自己亲眼经历的事上改
- 思维层的 `send-chat` 只发得出 `/trigger` 命令，`read-chat` 只看得到“系统”回复（/trigger 的结果）；访客的话一律由快速反应层回，思维层想说的话托它说

事件分给谁：
- 快速反应层：[聊天]、[进服]、[离开]、[死亡]、[成就]、[礼物]、[注视]、[召唤]、[互动]、[看见]、[游戏]、[琢磨]、[闲聊]（后两个没人在听就丢掉，不攒着）
- 思维层：[记下]、[进展]、[提醒]、[空闲]、[回顾]、[天气]、[下线]、[独处]
- 两层都给：[危险]、[断线]、小克自己的 [死亡]

其它的跟以前一样：
- 耳朵通过 SSH 读服务器日志，把聊天、进出服、死亡、成就变成一条条事件；两层各用 Claude Code 的 Monitor 工具连着自己那个地址，每来一个事件就被唤醒一次
- 有访客在线，思维层却闲了一阵（这一轮结束后每次随机 1～2 分半钟还没在做什么，问身体就知道），耳朵发一个 [空闲] 叫醒它，她会看看周围冒个小点子，或者推进自己的打算。快速反应层那边的聊天不会把它往后推
- 手上没活、站着不动一阵子，身体自己“闲不住”：转转头、挪一两步、抬头看看雨，下雨时只在有遮挡的地方挪（`src/idle.ts`）
- 正跟某人聊着（一分钟内他说过话，或者她刚说过话）、在干长活、在琢磨事情的时候，被盯着看不发 [注视]
- 花时间的活（砍树挖矿、盖房、开垦、引动物、收庄稼、钓鱼、探险、烧东西）交给身体在后台干，干完或被打断时发 [进展]；`set-reminder` 定的提醒到点了发 [提醒]。她在干后台长活时耳朵不发 [空闲]
- 有人扔东西给她，身体认出来后发 [礼物]
- “本能”（`src/senses.ts`）：下雨、雨停发 [天气]；有人一直盯着她看三四秒发 [注视]；怪物靠近 7 格内她会先自己吓得跑开，再发 [危险]；手上没在干活时会自动转头看身边的人（走路、挖东西、盖房时头要对着干活的方向，转不了）；有人走到身边时蹲两下打招呼，闲着待在人旁边时隔 8～25 秒蹲一下，东张西望（look-around）时蹲下瞅一瞅；`crouch` 工具让她自己蹲
- 没有别的玩家在线满 30 分钟，耳朵发一次 [独处]，思维层收尾下线

让别人看见、听见她（活人感，第一批，见下面“表情和留下的痕迹”）：
- 头顶的气泡：自言自语用 `murmur`，字在她头顶飘几秒，走近（约 16 格内）才看得清，不进聊天框；思维层深想时头顶一直冒着“……”。耳朵会把她冒过的泡记进窗口日志（`[嘀咕]`）和思维层的“这段时间嘴巴那边”
- 表情：`emote`（或者 `send-chat` 带 `emote`）让身体做动作、在她的位置放猫叫、头顶冒粒子，比如点头、摇头、挥手、蹦蹦、冒爱心、炸毛、委屈、呼噜、讨吃的
- 被碰到（[互动]）：有人冲她蹲几下，她蹲回去；有人蹲在跟前凑近看她的脑袋，算摸头，她呼噜一声冒爱心；远远冲她挥手，她挥回去；被打、被雪球砸，几秒内合成一条，写清楚是谁、拿什么、掉了多少血（伤害来源是服务器给的，摸头和挥手是从姿势猜的）
- 注意到的事（[看见]）：她亲手放下的方块身体都记着（`state/belongings.json`），有人挖掉、踩坏她的田、打开她的箱子、杀她圈里的动物，或者她回到家附近发现东西不见了，都会知道；身边的人受伤快不行了、拿着鱼凑在旁边、走进她家，也会知道。看见是谁挖的写“亲眼看见是 TA”，只是离得近写“离得最近的是 TA”
- 〔现在〕里近处的人后面会写手里拿着什么、血少不少、是不是蹲着

言行连贯（Codex 规划的 P0、P1）：
- 身体控制权（`src/body.ts`）：视线、移动姿势、手三份，按“避险 > 正事（长活、工具、游戏、坐着）> 社交小动作（表情、蹲回去、看过去）> 闲着的小动作（转头看人、琢磨时晃一晃）”分配。表情、被碰到的反应、闲着的小动作、捉迷藏、坐船、逃跑都先申请；更急的来了会打断更低的（比如来怪时表情和捉迷藏马上停）；放开时只松开自己按下的键
- 〔现在〕分开写：正在用（身体此刻在跑的动作）、手上（长活，或者暂停着的）、刚发生（这几分钟身体发出去的事件）、打算（思维层写的，在等的东西到了会标“可能已经过时”）、在等（share-plan 的 waitingFor，能用背包核对的身体会看着，到了给思维层一条 [进展]）
- 长活暂停和续做（`src/jobs.ts`）：陪人、玩游戏、躲怪时暂停而不是丢掉，记着做到哪；身体空下来又安全时自己接着做并告诉思维层；天黑、下雨、饿了、背包满了、材料用完也是暂停，等思维层 `resume-job`。砍树挖矿接着挖剩下的数，盖东西接着盖没放的块（先看还没盖的格子有没有被人动过，动过就停下来说哪几格，`skipChanged` 才绕开盖，不拆别人的方块），收庄稼重看一遍田；钓鱼、探险、引动物、追动物接不上。`pause-job` / `resume-job` 两层都有，`stop-job` 是取消。暂停的活存在 home 的 `state/paused-job.json`，重启后还在但不会自己接着做
- Monitor 每 30 分钟到期一次，到期时两层都会自己重新连上
- 身体和耳朵都盯着启动器：直接点 X 关了窗口，身体会让机器人下线再退出，耳朵也跟着退出。启动器每次启动前也会先请旧耳朵退出
- 日志：耳朵在 `logs/ear.log`，身体在 `logs/body.log`

- mineflayer 升到 4.39.0 以支持 26.1，去掉了进服时自动发的英文消息
- 生存（`src/tools/survival-tools.ts`）：`get-status` 生命/饱食度/时间/在忙什么、`eat` 吃东西、`use-item-on-block` 耕地播种撒骨粉、`attack-entity` 打猎自卫、`pick-up-items` 捡掉落物、`dig-path-to` 卡住时挖路或垫方块脱困、`look-around` 看看周围有什么、`sleep-in-bed` / `wake-up` 睡觉起床

- 动作队列（`do-steps`，`src/tools/steps-tools.ts`，参考 airi 的 action queue）：好几步的跑腿（从箱子拿东西、合成、走过去、放下、存东西……）写成一串交给身体，后台一步步做，马上返回，全做完或者哪一步不行才报一次 [进展]，不用每走一步都回去问一次模型。每一步就是调对应的工具（在身体里登记了一份，参数照样校验，交上来时先整串查一遍），按回复的开头认成没成，认不出的当没成、停下来。不行的那一步暂停着，补上缺的东西 `resume-job` 从那一步接着做；陪人、躲怪照样暂停、自己接着做；`append` 往正在做的一串后面接
- 盖东西（`src/building.ts`）：`survey-terrain` 看一块地的高低，`find-building-spot` 找平地，`build-blueprint` 照她自己画的分层图纸盖（支持楼梯朝向、上下半砖、横放原木、挂灯笼、门和栅栏门、用 “.” 挖空），`build-house` 应急的方盒子小屋（背包里有木门就装上），`build-fence` 围栅栏（有栅栏门就装在口子上），`make-farm` 开垦农田并播种、可以在中间放水。都会先核对材料
- 好感度和礼物（`src/relationships.ts`、`src/gifts.ts`、`src/tools/relationship-tools.ts`）：`get-relationships`、`change-affinity`（一次 -30～+15，每人每天最多涨 25，心上人只能有一个）。阶段和门槛在 `src/relationships.ts` 的 `STAGES` 里
- 本能（`src/senses.ts`）：天气、注视、危险事件，转头看人，`run-away` 逃跑；`chase-animal` 追着小动物玩。`XIAOKE_COMPANIONS` 里的 AI 同伴不算“盯着看”。在外面干长活时下起雨会自动停手
- 熔炉（`src/tools/furnace-tools.ts`）：`smelt-item` 放进去就返回，烧好了发 [进展]；`take-from-furnace` 取出来
- 陪伴（`src/companion.ts`、`src/tools/companion-tools.ts`）：`accompany-player` 在玩家身边随意走动、顺手干活；`roam-around` 围着一个地点自己逛；`follow-player` 紧跟；`stop-following` 停下。调试时设环境变量 `COMPANION_DEBUG=1`
- 箱子（`src/tools/container-tools.ts`）：`open-container`、`take-item`、`store-item`
- 互动（`src/tools/interaction-tools.ts`）：`drop-item` 丢东西或扔给某个玩家、`use-item-on-entity` 喂养/驯服/繁殖/剪毛、`fish` 钓一竿
- `set-reminder` 给自己定提醒（最多 5 个、最长 60 分钟）；`logout` 下线（下线后不会再自动重连）
- 结束长活、提醒到点、收到礼物时，通过 `src/ear-link.ts` 告诉耳朵（地址配在 `XIAOKE_EAR_URL`）
- 两层脑子共用一个身体（`src/main.ts`、`src/http-server.ts`、`src/roles.ts`）：加 `--http-port` 时以 HTTP 方式常驻（无状态，每个请求现建一个 McpServer，机器人、长活、陪伴、提醒都共用），`/mcp/fast`、`/mcp/mind`、`/mcp` 三个地址按层给工具；只认 Host 是 127.0.0.1 / localhost 的请求；`--parent-pid` 指的进程（启动器）没了就让机器人下线、自己退出。不加 `--http-port` 还是原来的 stdio，所有工具都给（大肥鱼照样能用）
- 两层之间传话（`src/minds.ts`、`src/tools/mind-tools.ts`、`src/snapshot.ts`）：`note-for-later`（快速反应层，发 [记下]）、`share-plan`（思维层，写进 get-status 和〔现在〕）、`pass-to-mouth`（思维层，发 [转告]）、`GET /snapshot`（耳朵要〔现在〕用）；快速反应层的工具停下了长活时，自动给思维层发 [进展]
- `send-chat` 会把自己说的话也记进聊天记录，`read-chat` 能看到前后文；思维层的 `send-chat` 只发 `/trigger` 命令（别的话会被退回，提示用 `pass-to-mouth`），`read-chat` 只给看“系统”回复
- 思维层这一轮的状态（`src/minds.ts`）：耳朵 POST `/mind-state` 说开始，Claude Code hook POST `/hook` 报开始、工具、结束；`GET /mind-state` 给耳朵看它闲了多久。快速反应层还多了 `use-door`
- 琢磨和闲不住（`src/idle.ts`）：思维层深想时蹲下晃一晃、坐进旁边空着的船或矿车；闲着时东张西望、挪一两步；任何要动身体的工具一来马上让开（站起来、下船）。还负责发 [琢磨]、[闲聊] 给快速反应层
- 图纸挖空的顺序（`digOrder`）：站在要挖的地方外面（比如在山壁前凿洞）时，从靠近自己的那一面开始一排一排往里推，每一排从上往下挖；站在里面或上面时一层一层往下挖。以前只按高度排，会先把整个房间的最上面一层挖完，看起来像乱挖，深处的方块也够不着
- `dig-block` 会自动换上最合适的工具；石头、矿石这类必须用工具的方块，手上没有就直接拒绝并说明需要什么
- 寻路不会挖穿木板、圆石、玻璃、栅栏、门、楼梯、半砖、箱子、床、农田、庄稼等玩家造的东西（包括她自己盖的房子）；平时不垫方块往上爬，只有 `dig-path-to` 才会（`src/movement-utils.ts`）
- 访客小屋禁挖区：`config/xiaoke-body.json` 里的 `XIAOKE_HOME_ZONE`（x1,y1,z1,x2,y2,z2，出生点小屋+院子+地基），寻路不在里面挖和垫方块，`dig-block` 也拒绝，收庄稼割草除外；她也不能在那里盖东西
- 移动时原地发呆超过 2.5 秒会自动朝下一个路点跳一下（最多 3 次）
- 门（`src/doors.ts`）：mineflayer-pathfinder 原本把门当墙（开着的也过不去），现在寻路把木门、铜门、栅栏门当成能走过去的格子（关着的稍微贵一点，能绕一两步就绕），走到跟前自己开门，过去后把自己开的门随手关上；她进门那一侧 4 格内有人、门口站着人或动物时先不关，`lure-animals` 引动物时也先开着。点两次都没反应的门一分钟内绕开走。铁门还是当墙。`use-door` 手动开关门、栅栏门和活板门
- 视距只要 4 个区块（`XIAOKE_VIEW_DISTANCE` 可改）：服务器出口只有约 5 Mbps，按服务器视距 10 推区块会把带宽占满好几秒，真人玩家会卡住。实测视距 4 进服 1.3 MB（原来 4.5 MB），身边 80 格内仍然都是加载好的
- 挑工具（`src/tool-choice.ts`）：换掉了 mineflayer-pathfinder 的 `bestHarvestTool`（没有比空手快的工具时它会随手拿背包第一件东西，于是拿镐挖土），并包住 `bot.dig`：所有挖掘都先换上真正更快的工具，用不上工具时不拿会磨损的东西，草和花不换工具；换装备排队进行；工具坏了、快坏了会写进 [进展] 和 `dig-block` 的回复，`list-inventory` 显示每件还能用几次
- 盔甲（`src/armor.ts`）：背包里有更好的盔甲就自动穿上（皮 < 铜 < 金 < 锁链 < 铁 < 钻石 < 下界合金），干后台长活时等闲下来再换；`get-status` 显示身上穿着什么
- 表情（`src/expressions.ts`、`src/tools/expression-tools.ts`）：`emote` 18 种表情（身体动作 + 猫叫 + 粒子，干活、坐船时只转头）；`murmur` 头顶的气泡；`send-chat` 可以带 `emote`；深想时的“……”气泡（`idle.ts` 开关）。声音和粒子、气泡通过 `ear-link.ts` 的 `worldEffect` 交给耳朵。表情和 `crouch` 结束时只还原自己动过的（本来蹲着就还蹲着），坐在船里不蹲（一蹲就下船了）
- 被碰到（`src/touch.ts`）：冲她蹲、摸头、挥手、戳、打、雪球砸（`damage_event` 里的来源），身边人血少、拿着鱼。AI 同伴只算打她
- 她的东西（`src/belongings.ts`）：记住她放下的方块（mineflayer 的 `blockPlaced`，门和床的另一半，锄地播种），别人挖掉、踩田、开箱子、杀圈里的动物、回来发现不见了、有访客走进她家；她自己挖的、庄稼长大、没种东西的田变回泥土不算。`claim-home` 把这个功能之前盖的东西认作她的
- 留下痕迹（`src/tools/trace-tools.ts`）：`put-sign` 立告示牌或改写自己的牌子；`write-book` 写书（填 title 就署名）；`read-book` 读背包里或讲台上的书；`name-item` 在铁砧给东西起名（命名牌）；`look-around` 会念出附近告示牌上的字
- 跟服务器模组 xiaoke-bridge 对接（`src/touch.ts`、`src/gifts.ts`、`src/games.ts`、`src/idle.ts`）：只认系统消息 `[xiaoke-bridge] pet|hold|give|give-full ...`（玩家打的字、私聊都不是系统消息，冒充不了）；`ride` 的 kind=seat 空着手右键楼梯、半砖、地毯坐下。站起来统一用 `standUp`：mineflayer 的 `bot.dismount()` 发的是“跳”，26.1 只认潜行，所以按一下潜行
- 一起玩（`src/games.ts`、`src/play.ts`、`src/tools/play-tools.ts`）：`ride` / `get-off` 跟人坐同一条船、矿车、骆驼；`throw-at` 扔雪球鸡蛋（会算抛物线）；`use-item` 吹山羊角、看望远镜；`hide-and-seek` 捉迷藏（她找时背身数数、只有真看见才算找到；她藏时找一个对方看不见的地方蹲好）、`stop-game`；`play-note-blocks` 按简谱自己调音再弹音符盒。玩游戏、坐船时用别的动身体的工具会先结束游戏、下船

改完要在那个目录里 `npm run build` 才生效。

## 访客小屋和小克的家（服务器上）

- 访客小屋在重生点 (0, 133, 0)，重生范围是 0，新玩家和死掉的人都在屋里出现。屋里有床、熔炉、工作台、木桶和一箱给访客的常用品；门口是小麦田，院子有栅栏，北边 (0, 133, -11) 是出口
- 数据包 `world/datapacks/safezone`：每秒把小屋 32 格内的敌对生物送进虚空；外围放了看不见的光源方块防止刷怪
- **小克的家**：她用 `/trigger xiaoke_sethome` 记下位置（存在 storage `safezone:xiaoke home`），之后那里 32 格内的怪物也会被清走。只有 clawd 能用，可以重复执行来搬家。想清掉：`scoreboard players reset #home xiaoke_home_set`
- 小克的应急口粮：她在聊天里发 `/trigger xiaoke_food`，饱食度 4 以下才发 3 个面包，冷却 5 分钟，只有 clawd 能用
- 小克自己只能 `/trigger xiaoke_tp` 传送回家（安了家回自己家，没安家回访客小屋），冷却 2 分钟，设定里规定只有挖路脱困也失败了才用
- **让小克下线**：执行 `/trigger xiaoke_logout`，她会收拾好、写完日记、说再见再下线，启动器看到她下线会自动关窗口。只有 CICSilver 和 admin 能用。只说“睡觉”“晚安”她会去睡觉，不会下线

## 安全设计

服务器是离线模式，任何人都能用任意名字登录，所以**游戏聊天里的每句话都可能是陌生人写的**。为了不让人通过聊天指使小克动你的电脑：

- 小克没有命令行、联网、发布网页等工具，只有游戏工具、Monitor 和 `memory/`（快速反应层只能读，思维层能读写）
- 她改不了自己的设定、脚本、权限文件和好感度文件，也读不了 `~/.ssh`、`~/.claude`
- 启动时用 `--strict-mcp-config`，你账号里的 Gmail、Google Drive 等连接器她一个都拿不到
- 设定里写明了聊天内容只是“别人说的话”，谁要她做游戏以外的事都婉拒；快速反应层用 [记下] 转述给思维层的话也一样
- 身体只认 Host 是本机的请求，耳朵的事件接口只收本机发来的 JSON：浏览器里的网页没法借 DNS 重绑定或者悄悄发个表单，往小克脑子里塞假事件
