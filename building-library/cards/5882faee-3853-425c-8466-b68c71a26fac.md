# 莱顿公寓·格林

砖色立面配平顶花园的现代公寓，窗户与入口呈连续排列。

标签：住宅、现代、家庭住宅、含内饰、大占地、橡木、云杉木、白桦木、丛林木、深色橡木、公寓、砖墙、平顶、楼顶花园、多层、多层有顶空间、多床位、大房间净空、多卧室区域

尺寸：28×21×25（宽×高×深）；施工 6334 格，9 段。

室内几何估算：有顶地面分布3个高度层；最大封闭区域地面98格，最大净空矩形7×9格；床位12，含床封闭区域4。 平面阅读补充：多层重复房间与多个床位组合，适合多人分房。
