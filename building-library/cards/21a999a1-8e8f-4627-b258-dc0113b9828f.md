# 混凝土小别墅

白色平台与深色立面形成竖向现代住宅，带多层阳台和大窗。

标签：住宅、现代、家庭住宅、含内饰、中等占地、橡木、云杉木、白桦木、丛林木、深色橡木、白墙、深色立面、平顶、阳台、多层、大窗、多层有顶空间

尺寸：16×17×20（宽×高×深）；施工 1922 格，2 段。

室内几何估算：有顶地面分布2个高度层；最大封闭区域地面21格，最大净空矩形4×4格；床位1，含床封闭区域0。

[室内平面图](../previews/21a999a1-8e8f-4627-b258-dc0113b9828f-floors.svg)

水体、耕地种植结合现场另外安排；花盆保留，花草由小克现场挑选；可选配色：原配色、易获取材料、金合欢暖色

## 材料替换

- 橡木配色组：oak_leaves、oak_button。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 云杉木配色组：stripped_spruce_wood、spruce_wood、spruce_trapdoor、spruce_fence、spruce_fence_gate。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 白桦木配色组：birch_door、birch_fence、birch_stairs。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 丛林木配色组：jungle_leaves、jungle_stairs。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 深色橡木配色组：dark_oak_log、dark_oak_door。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 墙体与屋顶石材：smooth_quartz_stairs、sandstone_wall。按完整方块、楼梯、台阶、围墙分别配对；整体配色与玩家商量。
- 窗户：glass_pane、pink_stained_glass_pane。玻璃板保持板形，玻璃块保持块形。
