# 泳池小别墅

横向舒展的白色现代别墅，配泳池、整排窗和二层平台。

标签：住宅、现代、家庭住宅、含内饰、大占地、橡木、云杉木、泳池、两层、平顶、白墙、多层有顶空间

尺寸：18×10×23（宽×高×深）；施工 1061 格，2 段。

室内几何估算：有顶地面分布2个高度层；最大封闭区域地面56格，最大净空矩形9×3格；床位1，含床封闭区域0。

[室内平面图](../previews/c0f8b6ba-bf2c-4a2c-9077-cf81fae35d56-floors.svg)

水体、耕地种植结合现场另外安排；花盆保留，花草由小克现场挑选；告示牌位置保留，文字由小克现场填写；可选配色：原配色、易获取材料、金合欢暖色

## 材料替换

- 橡木配色组：oak_leaves、oak_door。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 云杉木配色组：spruce_planks、spruce_stairs、spruce_trapdoor、spruce_sign。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 墙体与屋顶石材：smooth_quartz_stairs。按完整方块、楼梯、台阶、围墙分别配对；整体配色与玩家商量。
- 窗户：light_gray_stained_glass_pane。玻璃板保持板形，玻璃块保持块形。
