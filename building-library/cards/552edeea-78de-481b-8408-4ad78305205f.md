# 布吉舞曲之家

木质拱门、绿化屋顶和平台组成的幻想住宅，开放空间与水景相连。

标签：住宅、中世纪、欧式、幻想、含内饰、大占地、橡木、云杉木、白桦木、丛林木、金合欢木、诡异木、绿化屋顶、拱门、露台、水景、开放空间、多层有顶空间、多床位

尺寸：28×25×35（宽×高×深）；施工 4747 格，10 段。

室内几何估算：有顶地面分布3个高度层；最大封闭区域地面25格，最大净空矩形3×5格；床位3，含床封闭区域1。

[室内平面图](../previews/552edeea-78de-481b-8408-4ad78305205f-floors.svg)

施工使用74格临时泥土支撑，收尾图纸会收起；花盆保留，花草由小克现场挑选；告示牌位置保留，文字由小克现场填写；可选配色：原配色、易获取材料、金合欢暖色
