# 大型农舍

横向展开的大型农舍，长屋顶配连续门廊，适合优先考虑占地和家庭生活的方案。

标签：住宅、中世纪、田园、农田、含内饰、大占地、橡木、深色橡木、已去装饰烟雾、长屋、尖顶、门廊、家庭住宅、多层有顶空间

尺寸：27×18×29（宽×高×深）；施工 4201 格，8 段。

室内几何估算：有顶地面分布3个高度层；最大封闭区域地面149格，最大净空矩形5×9格；床位1，含床封闭区域1。 平面阅读补充：横向展开的侧翼较多，室内以长条房间和中部连通区为主，适合分配公共区与卧室。

[室内平面图](../previews/8d326368-4bf1-4e0c-8629-aca45cd8dc3b-floors.svg)

已省去11格蜘蛛网装饰烟雾；花盆保留，花草由小克现场挑选；可选配色：原配色、易获取材料、金合欢暖色

## 材料替换

- 橡木配色组：oak_fence、oak_log、oak_fence_gate、oak_door、oak_pressure_plate、oak_planks、oak_stairs、oak_button、oak_trapdoor、oak_slab。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 深色橡木配色组：dark_oak_planks、dark_oak_slab。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 墙体与屋顶石材：cobblestone、cobblestone_slab、cobblestone_wall、cobblestone_stairs。按完整方块、楼梯、台阶、围墙分别配对；整体配色与玩家商量。
- 窗户：glass_pane。玻璃板保持板形，玻璃块保持块形。
