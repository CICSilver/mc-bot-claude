# 白桦木砂岩小屋

白桦木与砂岩的明亮小屋，正面尖山墙突出，适合清爽田园配色。

标签：住宅、欧式、浅色、含内饰、中等占地、橡木、云杉木、白桦木、尖顶、白墙、田园、多层有顶空间、多床位

尺寸：16×13×15（宽×高×深）；施工 1065 格，2 段。

室内几何估算：有顶地面分布2个高度层；最大封闭区域地面63格，最大净空矩形10×4格；床位2，含床封闭区域1。

[室内平面图](../previews/83a6be69-2289-45d4-a3a7-6960fc514122-floors.svg)

水体、耕地种植结合现场另外安排；花盆保留，花草由小克现场挑选；告示牌位置保留，文字由小克现场填写；可选配色：原配色、易获取材料、金合欢暖色

## 材料替换

- 橡木配色组：oak_fence、oak_leaves。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 云杉木配色组：spruce_stairs、spruce_trapdoor、spruce_slab、spruce_sign、spruce_button、spruce_planks。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 白桦木配色组：stripped_birch_log、birch_planks、birch_trapdoor、birch_slab、birch_pressure_plate、birch_fence_gate、birch_stairs。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 墙体与屋顶石材：sandstone_stairs、smooth_sandstone、smooth_sandstone_stairs、sandstone_wall、smooth_sandstone_slab。按完整方块、楼梯、台阶、围墙分别配对；整体配色与玩家商量。
- 窗户：light_blue_stained_glass_pane。玻璃板保持板形，玻璃块保持块形。
