# 日式住宅·三

宽阔庭院配紫色层叠屋顶和外廊，是这批体量较大的日式外观模板。

标签：住宅、日式、大占地、云杉木、白桦木、金合欢木、深色橡木、红树木、竹、诡异木、紫色屋顶、层叠屋檐、庭院、多层、多层有顶空间、内饰待布置

尺寸：40×35×33（宽×高×深）；施工 6585 格，31 段。

室内几何估算：有顶地面分布4个高度层；最大封闭区域地面55格，最大净空矩形6×4格；床位0，含床封闭区域0。

[室内平面图](../previews/fd6251bb-ec3a-4ee6-8e43-cd02d845cb61-floors.svg)

施工使用292格临时泥土支撑，收尾图纸会收起；水体、耕地种植结合现场另外安排；告示牌位置保留，文字由小克现场填写；可选配色：原配色、易获取材料、金合欢暖色
