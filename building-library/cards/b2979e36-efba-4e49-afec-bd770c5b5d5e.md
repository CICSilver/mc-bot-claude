# 双层农田小院木屋

浅木两层住宅搭配农田和小院，屋顶平台便于增加生活设施。

标签：住宅、中世纪、田园、农田、两层、木屋、含内饰、大占地、橡木、云杉木、庭院、平顶、多层有顶空间、多床位

尺寸：31×13×28（宽×高×深）；施工 1824 格，6 段。

室内几何估算：有顶地面分布3个高度层；最大封闭区域地面44格，最大净空矩形4×11格；床位2，含床封闭区域1。

[室内平面图](../previews/b2979e36-efba-4e49-afec-bd770c5b5d5e-floors.svg)

水体、耕地种植结合现场另外安排；花盆保留，花草由小克现场挑选；告示牌位置保留，文字由小克现场填写；可选配色：原配色、易获取材料、金合欢暖色

## 材料替换

- 橡木配色组：oak_log、oak_stairs、oak_slab、oak_planks、oak_leaves。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 云杉木配色组：spruce_slab、spruce_stairs、spruce_fence、spruce_fence_gate、spruce_planks、spruce_trapdoor、spruce_sign、spruce_door。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 窗户：glass。玻璃板保持板形，玻璃块保持块形。
