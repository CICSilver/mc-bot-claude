# 金合欢深色橡木小屋·全内饰

橙色陡尖顶搭深色木骨架，入口两侧花草丰富，带完整内饰。

标签：住宅、中世纪、幻想、深色、含内饰、中等占地、橡木、云杉木、白桦木、丛林木、金合欢木、深色橡木、红树木、樱花木、陡尖顶、橙色屋顶、深色梁柱、花草装饰、多层有顶空间、多床位

尺寸：16×20×22（宽×高×深）；施工 1758 格，2 段。

室内几何估算：有顶地面分布3个高度层；最大封闭区域地面33格，最大净空矩形6×3格；床位2，含床封闭区域0。

[室内平面图](../previews/552a8eb3-9c8a-472a-a8f6-c203e1d909d3-floors.svg)

水体、耕地种植结合现场另外安排；花盆保留，花草由小克现场挑选；告示牌位置保留，文字由小克现场填写；可选配色：原配色、易获取材料、金合欢暖色
