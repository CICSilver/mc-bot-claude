# 精灵小屋·Kuky

青色尖顶与侧边小塔形成错落轮廓，门窗周围有花草点缀。

标签：住宅、中世纪、幻想、含内饰、大占地、橡木、云杉木、白桦木、丛林木、诡异木、青色屋顶、塔楼、尖顶、花草装饰、多层有顶空间、多床位

尺寸：25×30×25（宽×高×深）；施工 2032 格，8 段。

室内几何估算：有顶地面分布2个高度层；最大封闭区域地面41格，最大净空矩形7×4格；床位2，含床封闭区域1。

[室内平面图](../previews/222d7749-8065-4146-952c-43d51275addf-floors.svg)

施工使用99格临时泥土支撑，收尾图纸会收起；花盆保留，花草由小克现场挑选；可选配色：原配色、易获取材料、金合欢暖色

- 橡木配色组：oak_log、oak_leaves、oak_trapdoor、oak_planks、stripped_oak_wood、oak_stairs。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 云杉木配色组：spruce_planks、spruce_stairs、spruce_door、spruce_trapdoor、spruce_fence、spruce_slab、spruce_pressure_plate、spruce_fence_gate。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 白桦木配色组：birch_log、birch_wood、birch_stairs。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 丛林木配色组：jungle_trapdoor。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 诡异木配色组：warped_slab、warped_stairs。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 墙体与屋顶石材：smooth_quartz、stone_brick_wall、cobblestone_wall。按完整方块、楼梯、台阶、围墙分别配对；整体配色与玩家商量。
- 窗户：glass_pane。玻璃板保持板形，玻璃块保持块形。
