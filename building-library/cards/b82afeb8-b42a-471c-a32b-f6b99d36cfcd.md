# 竹顶日式房屋

竹色大屋顶配白墙、深木边框和门廊，整体轮廓低缓开阔。

标签：住宅、日式、大占地、橡木、云杉木、白桦木、金合欢木、深色橡木、樱花木、竹、竹材、黄色屋顶、白墙、门廊、内饰待布置

尺寸：25×18×25（宽×高×深）；施工 2321 格，3 段。

室内几何估算：有顶地面分布1个高度层；开放空间与露台可按用途划分；床位0，含床封闭区域0。

可选配色：原配色、易获取材料、金合欢暖色
