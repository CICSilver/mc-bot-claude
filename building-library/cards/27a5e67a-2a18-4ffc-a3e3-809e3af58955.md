# 公寓二·格林

成排窗户的现代公寓，深色立面配红色侧墙，适合较大规模的多人住宅。

标签：住宅、现代、家庭住宅、含内饰、大占地、橡木、云杉木、白桦木、金合欢木、深色橡木、公寓、多层、平顶、多层有顶空间、多床位、多卧室区域

尺寸：27×19×24（宽×高×深）；施工 6333 格，9 段。

室内几何估算：有顶地面分布3个高度层；最大封闭区域地面25格，最大净空矩形3×6格；床位24，含床封闭区域12。 平面阅读补充：多个重复的小居住单元，含床区域较多，适合多人分房。

[室内平面图](../previews/27a5e67a-2a18-4ffc-a3e3-809e3af58955-floors.svg)

花盆保留，花草由小克现场挑选；可选配色：原配色、易获取材料、金合欢暖色

- 橡木配色组：oak_log、oak_door、oak_trapdoor。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 云杉木配色组：stripped_spruce_wood、spruce_trapdoor、spruce_leaves。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 白桦木配色组：birch_door。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 金合欢木配色组：acacia_slab、acacia_stairs、acacia_trapdoor。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 深色橡木配色组：dark_oak_stairs、dark_oak_trapdoor。整组替换相同形状；保留朝向、台阶位置、门窗开合。

- 窗户：white_stained_glass_pane、gray_stained_glass、glass、light_gray_stained_glass。玻璃板保持板形，玻璃块保持块形。
