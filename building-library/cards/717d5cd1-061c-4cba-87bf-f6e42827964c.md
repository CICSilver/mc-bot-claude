# 双方块农田木屋

两块木质体量组合的现代生存住宅，大窗与平顶平台方便联系农田。

标签：住宅、现代、田园、农田、木屋、含内饰、中等占地、橡木、云杉木、平顶、大窗、多层有顶空间、多床位

尺寸：22×11×13（宽×高×深）；施工 811 格，2 段。

室内几何估算：有顶地面分布2个高度层；最大封闭区域地面21格，最大净空矩形3×4格；床位2，含床封闭区域1。

[室内平面图](../previews/717d5cd1-061c-4cba-87bf-f6e42827964c-floors.svg)

水体、耕地种植结合现场另外安排；花盆保留，花草由小克现场挑选；告示牌位置保留，文字由小克现场填写；可选配色：原配色、易获取材料、金合欢暖色

## 材料替换

- 橡木配色组：oak_planks、oak_stairs、oak_door、oak_leaves。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 云杉木配色组：spruce_slab、spruce_fence、spruce_planks、spruce_sign、spruce_trapdoor、spruce_stairs。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 窗户：glass、glass_pane。玻璃板保持板形，玻璃块保持块形。
