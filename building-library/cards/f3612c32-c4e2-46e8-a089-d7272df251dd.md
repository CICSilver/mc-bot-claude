# 黄顶吊脚楼

黄色层叠屋顶配架空木柱和外侧露台，适合庭院或高脚住宅方案。

标签：住宅、中式、大占地、橡木、云杉木、白桦木、丛林木、金合欢木、深色橡木、红树木、竹、黄色屋顶、高脚屋、露台、层叠屋檐、开放空间、多层有顶空间、内饰待布置

尺寸：20×20×24（宽×高×深）；施工 1624 格，3 段。

室内几何估算：有顶地面分布2个高度层；开放空间与露台可按用途划分；床位0，含床封闭区域0。

[室内平面图](../previews/f3612c32-c4e2-46e8-a089-d7272df251dd-floors.svg)

施工使用50格临时泥土支撑，收尾图纸会收起；花盆保留，花草由小克现场挑选；告示牌位置保留，文字由小克现场填写；可选配色：原配色、易获取材料、金合欢暖色
