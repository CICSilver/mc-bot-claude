# 日式住宅·二

层叠灰瓦屋顶配木质外廊与阳台，适合逐层安排生活用途。

标签：住宅、日式、大占地、橡木、云杉木、白桦木、丛林木、金合欢木、深色橡木、诡异木、灰瓦屋顶、木结构、阳台、层叠屋檐、多层、多层有顶空间、内饰待布置

尺寸：20×27×29（宽×高×深）；施工 4222 格，11 段。

室内几何估算：有顶地面分布3个高度层；最大封闭区域地面37格，最大净空矩形6×3格；床位0，含床封闭区域0。

[室内平面图](../previews/a706b38a-6a12-47fa-9064-02e001c562e0-floors.svg)

施工使用39格临时泥土支撑，收尾图纸会收起；水体、耕地种植结合现场另外安排；花盆保留，花草由小克现场挑选；告示牌位置保留，文字由小克现场填写；可选配色：原配色、易获取材料、金合欢暖色
