# 奥术旅馆

紫色尖屋顶和木质门廊组成的奥术风住宅，适合喜欢鲜明配色的方案。

标签：住宅、中世纪、幻想、含内饰、大占地、橡木、云杉木、丛林木、深色橡木、樱花木、绯红木、紫色屋顶、尖顶、门廊、多层有顶空间

尺寸：21×21×31（宽×高×深）；施工 2668 格，6 段。

室内几何估算：有顶地面分布2个高度层；最大封闭区域地面71格，最大净空矩形12×3格；床位1，含床封闭区域1。

[室内平面图](../previews/717cf4b3-3405-4e99-a209-aec792985793-floors.svg)

水体、耕地种植结合现场另外安排；花盆保留，花草由小克现场挑选；告示牌位置保留，文字由小克现场填写；可选配色：原配色、易获取材料、金合欢暖色

- 橡木配色组：oak_fence、oak_slab、stripped_oak_wood、oak_leaves、oak_stairs、oak_pressure_plate、oak_door、oak_trapdoor、oak_log、oak_planks、oak_fence_gate。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 云杉木配色组：spruce_fence、spruce_slab、spruce_planks、spruce_trapdoor、spruce_fence_gate、spruce_stairs、spruce_sign、stripped_spruce_wood。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 丛林木配色组：stripped_jungle_wood。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 深色橡木配色组：dark_oak_sign。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 樱花木配色组：cherry_trapdoor。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 绯红木配色组：crimson_stairs、crimson_slab。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 墙体与屋顶石材：stone_bricks、cobblestone、cobblestone_wall。按完整方块、楼梯、台阶、围墙分别配对；整体配色与玩家商量。
- 窗户：pink_stained_glass、black_stained_glass_pane。玻璃板保持板形，玻璃块保持块形。
