# 乡村别墅

暖色木质乡村住宅，尖顶与入口门廊层次分明。

标签：住宅、中世纪、田园、家庭住宅、含内饰、中等占地、橡木、云杉木、白桦木、木屋、尖顶、门廊、多层有顶空间

尺寸：21×20×18（宽×高×深）；施工 2076 格，2 段。

室内几何估算：有顶地面分布3个高度层；最大封闭区域地面58格，最大净空矩形10×3格；床位1，含床封闭区域0。 平面阅读补充：主层围绕楼梯和转角布置，上层适合安排睡眠区。

[室内平面图](../previews/25a56faf-d995-4cd5-9146-4c9793aaa455-floors.svg)

可选配色：原配色、易获取材料、金合欢暖色

## 材料替换

- 橡木配色组：oak_planks、oak_leaves、oak_stairs。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 云杉木配色组：spruce_log、spruce_stairs、spruce_fence、spruce_planks、spruce_door、spruce_trapdoor、spruce_slab。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 白桦木配色组：birch_leaves。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 墙体与屋顶石材：cobblestone、cobblestone_slab、quartz_slab。按完整方块、楼梯、台阶、围墙分别配对；整体配色与玩家商量。
