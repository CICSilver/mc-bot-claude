# 三层木制别墅

浅色墙体、深色梁柱与木屋顶的三层别墅，侧面有突出的阳台平台。

标签：住宅、中世纪、欧式、家庭住宅、三层、木屋、含内饰、中等占地、橡木、云杉木、白桦木、金合欢木、尖顶、阳台、浅色、多层有顶空间、多床位

尺寸：22×21×15（宽×高×深）；施工 1589 格，2 段。

室内几何估算：有顶地面分布3个高度层；最大封闭区域地面62格，最大净空矩形9×6格；床位2，含床封闭区域1。 平面阅读补充：竖向三层与长方形室内搭配，公共区和睡眠区适合分层安排。

[室内平面图](../previews/3a4be4e9-50a0-4bd3-969f-507906191b25-floors.svg)

花盆保留，花草由小克现场挑选；可选配色：原配色、易获取材料、金合欢暖色

## 材料替换

- 橡木配色组：oak_button、oak_log、oak_planks、oak_stairs、stripped_oak_log、oak_door、oak_pressure_plate。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 云杉木配色组：spruce_stairs、spruce_slab、spruce_trapdoor、spruce_door、spruce_fence、spruce_pressure_plate、spruce_planks、spruce_fence_gate。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 白桦木配色组：birch_planks、birch_log、stripped_birch_log、birch_pressure_plate、birch_button、birch_fence、birch_stairs、birch_slab、birch_fence_gate。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 金合欢木配色组：acacia_trapdoor。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 墙体与屋顶石材：sandstone_wall。按完整方块、楼梯、台阶、围墙分别配对；整体配色与玩家商量。
- 窗户：glass_pane。玻璃板保持板形，玻璃块保持块形。
