# 商人之家

青色尖屋顶与高烟囱搭配木梁门廊，适合作为有辨识度的日常住宅。

标签：住宅、中世纪、幻想、含内饰、大占地、橡木、云杉木、白桦木、丛林木、金合欢木、深色橡木、红树木、诡异木、青色屋顶、烟囱、门廊、木屋、多层有顶空间、多床位

尺寸：24×30×25（宽×高×深）；施工 2547 格，5 段。

室内几何估算：有顶地面分布3个高度层；最大封闭区域地面41格，最大净空矩形4×8格；床位2，含床封闭区域1。
