# 乡村自建房

白色水平线条搭深色玻璃窗的多层自建房，各层有突出的阳台与平台。

标签：住宅、现代、大占地、白桦木、深色橡木、樱花木、苍白橡木、多层、阳台、大窗、白墙、多层有顶空间、大房间净空、内饰待布置

尺寸：29×25×22（宽×高×深）；施工 4553 格，5 段。

室内几何估算：有顶地面分布4个高度层；最大封闭区域地面266格，最大净空矩形9×18格；床位1，含床封闭区域1。

[室内平面图](../previews/ba1eb672-ac32-48d1-aba5-a9f56b3a02c8-floors.svg)

水体、耕地种植结合现场另外安排；可选配色：原配色、易获取材料、金合欢暖色

## 材料替换

- 白桦木配色组：birch_planks、birch_slab。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 深色橡木配色组：dark_oak_door。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 樱花木配色组：cherry_trapdoor、cherry_door。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 苍白橡木配色组：stripped_pale_oak_wood。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 墙体与屋顶石材：stone_bricks、deepslate_bricks、stone_brick_stairs、deepslate_tile_slab、deepslate_tile_wall、quartz_block、quartz_stairs、deepslate_tile_stairs、deepslate_tiles、quartz_slab。按完整方块、楼梯、台阶、围墙分别配对；整体配色与玩家商量。
- 窗户：glass_pane、glass、black_stained_glass_pane。玻璃板保持板形，玻璃块保持块形。
