# 中世纪海港小屋

高挑木屋顶配架空支柱与入口台阶，适合海港、岸边或整平场地。

标签：住宅、中世纪、水边、含内饰、中等占地、橡木、云杉木、白桦木、尖顶、木屋、高脚屋、多层有顶空间

尺寸：19×24×16（宽×高×深）；施工 2199 格，2 段。

室内几何估算：有顶地面分布3个高度层；最大封闭区域地面52格，最大净空矩形10×3格；床位1，含床封闭区域0。

[室内平面图](../previews/91b40ca2-6027-494d-8ab0-51f68a2b5a75-floors.svg)

告示牌位置保留，文字由小克现场填写；可选配色：原配色、易获取材料、金合欢暖色
