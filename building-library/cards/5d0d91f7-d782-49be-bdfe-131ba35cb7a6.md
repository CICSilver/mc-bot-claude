# 中世纪农舍

浅木两层农舍，正面窗户、阳台栏杆和入口台阶完整。

标签：住宅、中世纪、田园、农田、含内饰、中等占地、橡木、云杉木、白桦木、丛林木、两层、木屋、大窗、多层有顶空间、多床位

尺寸：15×14×19（宽×高×深）；施工 1379 格，3 段。

室内几何估算：有顶地面分布3个高度层；最大封闭区域地面34格，最大净空矩形4×7格；床位4，含床封闭区域0。

[室内平面图](../previews/5d0d91f7-d782-49be-bdfe-131ba35cb7a6-floors.svg)

施工使用6格临时泥土支撑，收尾图纸会收起；可选配色：原配色、易获取材料、金合欢暖色

## 材料替换

- 橡木配色组：oak_fence、oak_planks、oak_slab、oak_stairs、oak_pressure_plate、oak_trapdoor、oak_button、oak_door。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 云杉木配色组：spruce_stairs、spruce_log、spruce_planks、spruce_slab。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 白桦木配色组：birch_stairs。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 丛林木配色组：jungle_slab、jungle_planks、jungle_stairs。整组替换相同形状；保留朝向、台阶位置、门窗开合。
- 墙体与屋顶石材：cobblestone_stairs。按完整方块、楼梯、台阶、围墙分别配对；整体配色与玩家商量。
- 窗户：glass_pane、glass。玻璃板保持板形，玻璃块保持块形。
